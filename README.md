# Розовый кроссворд

React-приложение для тематических кроссвордов без регистрации. Сетка строится
автоматически по пересечениям слов, а введённые буквы, подсказки и добавленные
темы сохраняются в localStorage браузера.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

Статический результат появится в `dist/client`.

## Формат темы

```json
{
  "id": "coffee",
  "title": "Кофейная пауза",
  "description": "Небольшой кроссворд для бодрого утра",
  "emoji": "☕",
  "words": [
    { "answer": "АРАБИКА", "clue": "Самый распространённый сорт кофе" },
    { "answer": "БАРИСТА", "clue": "Мастер приготовления кофе" }
  ]
}
```

Через кнопку «Для автора» JSON можно вставить или загрузить файлом. В статической
версии GitHub Pages такая тема доступна только в браузере, где её импортировали.
Чтобы тема появилась у всех посетителей, добавьте её в `DEFAULT_PUZZLES` в
`lib/crossword.ts` либо подключите серверное хранилище.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` автоматически собирает и публикует
сайт при push в ветку `main`. В настройках репозитория откройте **Settings →
Pages** и выберите **GitHub Actions** как источник публикации.
